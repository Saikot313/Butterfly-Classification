TRAINING PROCESS

Teaching the model to see.

01

Dataset Preparation

Thousands of butterfly images are organized into multiple species classes for supervised learning.

02

Data Augmentation

Image transformations such as rotation, flipping and zooming help the model learn more robust visual features.

03

CNN Training

The custom CNN learns hierarchical visual patterns from butterfly wings and body structures.

04

Model Evaluation

The trained model is evaluated to understand how well it performs on unseen butterfly images.

05

Deployment

The trained model is integrated with a Flask API and connected to an interactive web interface.
